One fortune-cookie line for a crypto trader who has just been
liquidated: the trader's position went to the moon — the trader
just stayed behind with the bill.

## Run

```sh
node main.ts
```

Writes the fortune to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to
`/output/entry.txt`), after self-validating the gate: exactly one line,
1–160 characters, at most 20 words.
